# B/W Black & White — 3D E-Commerce Platform

Premium monochromatic 3D T-shirt e-commerce experience built with modern free-tier stack.

## Live Demo

Deployed on Vercel (link will be available after deployment).

## Features

- **Interactive 3D Hero & Product Views** (React Three Fiber)
- **3D Try-On Studio** — step-by-step avatar, color, size, pose workflow
- **Full Shopping Flow** — Cart drawer, multi-step checkout, order confirmation
- **Responsive Dark Theme** — Strict black & white design system
- **Product Collection / Men / Women / Bestsellers** pages
- **Product Detail** with live 3D color switching
- **Zustand** state management with localStorage persistence
- **Mock catalog** ready for Supabase / Prisma integration

## Tech Stack

| Layer        | Technology                          |
|--------------|-------------------------------------|
| Frontend     | React 19 + TypeScript + Vite        |
| Styling      | Tailwind CSS                        |
| 3D           | Three.js + React Three Fiber + Drei |
| State        | Zustand                             |
| Routing      | React Router v7                     |
| Icons        | Lucide React                        |

## Quick Start

```bash
cd bw-ecommerce
npm install
npm run dev
```

Open http://localhost:5173
